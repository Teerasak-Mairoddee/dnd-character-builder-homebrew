Build rules
  1. Abilities start at +0. Spend ability points to raise them, one point for each +1.
  2. You can lower up to two abilities to −1. Each one gives you a point back to spend elsewhere.
  3. Train skills. A trained skill is its ability's number +2. An untrained skill uses the ability's number.
  4. New tier, more to spend. Each tier gives 2 more ability points, raises the highest an ability can go by 1, and adds 1 skill training.
  5. Everything else is up to the table. Health, combat, gear and powers are handled by your homebrew rules, not this sheet.
Get inspiration

Ticking a skill means your character is trained in it, which adds +2 to that skill's number. Skills you leave unticked use the ability's number. The tier sets how many skills you can tick. Open What … does or tap ? next to a skill to see what it's used for.
